¿Cuál método es el más preciso para el mismo tamaño de paso h y por qué?

Para el mismo tamaño de paso h, el método de Runge-Kutta de Cuarto Orden (RK4) es indiscutiblemente el más preciso de los tres métodos evaluados tanto para la velocidad v(t) como para la altura y(t). A continuación se presenta la demostración fundamentada en la expansión en Series de Taylor, el orden del error de truncamiento y la geometría de pendientes en el intervalo [ti, ti+1].

1er ORDEN — O(h) 1 eval. f(t,v) / paso

Método de Euler Explícito

k₁ = f(tᵢ, vᵢ)
vᵢ₊₁ = vᵢ + h · k₁
yᵢ₊₁ = yᵢ + h · vᵢ

Limitación Geométrica: Asume que la derivada (aceleración y velocidad) calculada al inicio del intervalo permanece constante durante todo el paso h. Como la aceleración del cohete disminuye exponencialmente por el arrastre, la recta tangente inicial siempre apunta por encima de la curva real de velocidad.

Método de Heun (Predictor-Corrector)

k₁ = f(tᵢ, vᵢ)
k₂ = f(tᵢ + h, vᵢ + h·k₁)
vᵢ₊₁ = vᵢ + (h/2)·(k₁ + k₂)
yᵢ₊₁ = yᵢ + (h/2)·(vᵢ + v̂ᵢ₊₁)

Mejora Geométrica: Utiliza un paso de Euler como predictor para estimar el estado al final del intervalo y luego aplica la regla del trapecio promediando las pendientes inicial y final. Cancela el término de error de primer orden.

4to ORDEN — O(h⁴) ★ MÁS PRECISO

Runge-Kutta de 4to Orden (RK4)

k₁ = f(tᵢ, uᵢ)  |  k₂ = f(tᵢ + h/2, uᵢ + (h/2)·k₁)
k₃ = f(tᵢ + h/2, uᵢ + (h/2)·k₂)  |  k₄ = f(tᵢ + h, uᵢ + h·k₃)
uᵢ₊₁ = uᵢ + (h/6)·(k₁ + 2k₂ + 2k₃ + k₄)

Superioridad Matemática: Equivale a una serie de Taylor hasta el cuarto término para el vector de estado acoplado u = [v, y]ᵀ. Sondea la pendiente en el inicio (k₁), dos veces en el punto medio (k₂, k₃ con doble peso como en la Regla de Simpson 1/3) y al final (k₄).

Ley de Escalamiento del Error al Reducir el Paso h

Si reducimos el tamaño de paso a la mitad (h → h/2) o a la décima parte (h → h/10), el error global disminuye según la potencia del orden del método:

Método Orden Global Si h se divide entre 2 Si h se divide entre 10
Euler O(h¹) Error se reduce 2 veces Error se reduce 10 veces
Heun O(h²) Error se reduce 4 veces Error se reduce 100 veces
RK4 O(h⁴) Error se reduce 16 veces Error se reduce 10,000 veces
Conclusión para Ingeniería Aeroespacial y de Sistemas: Aunque RK4 requiere 4 evaluaciones de la función por cada paso (frente a 1 de Euler), para alcanzar la misma exactitud que logra RK4 con h = 2.0 s, el método de Euler necesitaría un paso h < 0.0005 s (más de 120,000 pasos frente a solo 30 pasos de RK4). Por ello, RK4 optimiza drásticamente el tiempo de CPU y evita la acumulación de errores de redondeo de punto flotante (IEEE 754).

Compromiso entre Complejidad Algorítmica, Error de Truncamiento y Redondeo (IEEE 754)

1. Costo de CPU por Iteración
En sistemas de telemetría en tiempo real, reducir excesivamente h en Euler incrementa linealmente el número de ciclos de reloj (N = t_max / h). RK4 logra precisión de orden O(h⁴) con solo 4N evaluaciones, liberando capacidad de procesamiento para control de actitud y navegación.
2. Truncamiento vs. Punto Flotante
El error total en un sistema informático es E_total = E_truncamiento + E_redondeo. Si en Euler elegimos un paso h microscópico para compensar su bajo orden O(h), millones de sumas sucesivas degradan la mantisa en aritmética binaria IEEE 754. RK4 evita este fenómeno usando pasos moderados.
3. Verificación y Validación (V&V)
En Ingeniería de Sistemas aplicada a misiones críticas (como el paso del cálculo manual al mainframe IBM 7090 en la NASA), contrastar un modelo analítico cerrado frente a integradores independientes constituye la base de las pruebas de aceptación del software de vuelo.
